# Nafees Hasnat

I build A/B test variations from briefs and Figma designs in vanilla JavaScript and CSS, mostly on Shopify in Intelligems and AB Tasty.

**Subscription buy box A/B test.** Pick a subscription and a delivery frequency, add to cart, and inspect the selling plan the store receives. Then re-render the app and check again.
[Live demo](https://nafeeshasnat.github.io/subscription-buy-box-ab-test/?v=b) · [Source](https://github.com/nafeeshasnat/subscription-buy-box-ab-test)

**Cart drawer A/B test.** Change quantities across the free-shipping threshold, add or remove the upsell, and close and reopen the drawer. The bar and offer are rebuilt from cart state every time.
[Live demo](https://nafeeshasnat.github.io/cart-drawer-ab-test/?v=b) · [Source](https://github.com/nafeeshasnat/cart-drawer-ab-test)

Client code is under NDA, so these are independent demos written in the same patterns I use in client tests.
